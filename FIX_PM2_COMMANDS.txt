AGGIORNAMENTO IMMEDIATO DEL SERVER
=================================

STEP 1 - AGGIORNAMENTO MANUALE:
```bash
ssh root@78.47.123.128
cd /home/highlander/app

# Forza sincronizzazione con repository
git fetch origin
git reset --hard origin/main

# Reinstalla e rebuilda
npm install
npm run build

# Restart completo PM2
pm2 restart highlander
pm2 status
pm2 logs highlander --lines 10
```

STEP 2 - AGGIORNA SCRIPT DEPLOY SUL SERVER:
```bash
# Modifica il deploy script
nano /home/highlander/deploy.sh

# Cambia la riga:
# pm2 reload highlander
# Con:
# pm2 restart highlander

# Salva (Ctrl+X, Y, Enter)
```

Il problema era che pm2 reload non applica completamente le modifiche al codice, mentre pm2 restart garantisce un riavvio completo dell'applicazione.
