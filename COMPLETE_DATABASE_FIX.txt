RISOLUZIONE COMPLETA DATABASE POSTGRESQL
=======================================

PROBLEMI IDENTIFICATI:
1. Database si chiama "highlander_prod" non "highlander_db"
2. Due utenti confusi: "highlander" e "highlander_db"
3. Connection string errata nell'applicazione
4. Database vuoto senza tabelle

SOLUZIONE:

1. Connetti al database corretto e verifica contenuto:
```bash
sudo -u postgres psql
\c highlander_prod
\dt
\q
```

2. Aggiorna ecosystem.config.cjs con il nome database corretto:
```bash
cd /home/highlander/app

cat > ecosystem.config.cjs << 'EOF'
module.exports = {
  apps: [{
    name: 'highlander',
    script: './dist/index.js',
    cwd: '/home/highlander/app',
    env: {
      NODE_ENV: 'production',
      PORT: 5000,
      DATABASE_URL: 'postgresql://highlander:HighlanderDB2024!@localhost:5432/highlander_prod',
      SMTP_USER: 'support@highlandergame.it',
      SMTP_PASSWORD: 'Calibro9!',
      FROM_EMAIL: 'support@highlandergame.it',
      SENDGRID_API_KEY: '',
      SESSION_SECRET: 'highlander-secure-session-2024',
      BASE_URL: 'https://highlandergame.it'
    },
    instances: 1,
    autorestart: true,
    watch: false,
    max_memory_restart: '1G',
    error_file: './logs/error.log',
    out_file: './logs/out.log',
    log_file: './logs/combined.log',
    time: true
  }]
}
EOF
```

3. Testa connessione:
```bash
psql "postgresql://highlander:HighlanderDB2024!@localhost:5432/highlander_prod"
\q
```

4. Se connessione OK, restart PM2:
```bash
pm2 delete highlander
pm2 start ecosystem.config.cjs
pm2 logs highlander --lines 10
```

Il database corretto è "highlander_prod", non "highlander_db".
