RISOLUZIONE REPOSITORY VUOTO SU GITHUB
======================================

Il repository appare vuoto perché il push non è andato a buon fine.

ESEGUI QUESTI COMANDI NELLA SHELL:

# 1. Rimuovi file di lock Git bloccato
rm -f .git/index.lock

# 2. Verifica stato repository
git status

# 3. Se necessario, aggiungi nuovamente i file
git add .

# 4. Forza il push su GitHub
git push -f origin main

# 5. Verifica su GitHub che i file siano presenti

ALTERNATIVA SE PERSISTE:

# Reset completo e nuovo push
git log --oneline
git reset --soft HEAD~1
git add .
git commit -m "Initial: App Highlander con PM2 e fix login"
git push -f origin main

VERIFICA FINALE:
- Vai su https://github.com/Fabiodi1995/highlander-serie-a
- Controlla che ci siano tutti i file del progetto
- Se il repository è ancora vuoto, eliminalo e ricrealo
