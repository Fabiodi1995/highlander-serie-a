RISOLUZIONE GIT LOCK PROBLEM
============================

Git ha un lock file bloccato. Esegui questi comandi nella shell:

# 1. Rimuovi il file di lock
rm -f .git/index.lock

# 2. Rimuovi remote esistente
git remote rm origin

# 3. Aggiungi tutti i file in una volta
git add .

# 4. Commit
git commit -m "Initial: App Highlander completa con PM2"

# 5. Aggiungi remote
git remote add origin https://github.com/Fabiodi1995/highlander-serie-a.git

# 6. Push
git branch -M main
git push -u origin main

ALTERNATIVA SE PERSISTE IL PROBLEMA:

# Reset completo
rm -rf .git
git init
git add .
git commit -m "Initial: App Highlander"
git remote add origin https://github.com/Fabiodi1995/highlander-serie-a.git
git branch -M main
git push -u origin main

Questo dovrebbe risolvere il lock e completare il push.
