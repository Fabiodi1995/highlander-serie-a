RISOLUZIONE LOCK GIT E DEPLOY IMMEDIATO
=====================================

PROBLEMA: Git lock impedisce commit delle modifiche debug.

SOLUZIONE MANUALE PER IL DEPLOY:

1. ACCEDI AL SERVER DIRETTAMENTE:
```bash
ssh root@78.47.123.128
cd /home/highlander/app
```

2. MODIFICA DIRETTAMENTE IL FILE IN PRODUZIONE:
```bash
nano client/src/pages/forgot-username.tsx
```

Aggiungi i console.log nella funzione onSubmit:
```javascript
console.log("Invio richiesta a /api/forgot-username con:", data);
console.log("Response status:", response.status);
console.log("Response data:", result);
console.error("Errore fetch:", error);
```

3. REBUILD E RESTART:
```bash
npm run build
pm2 restart highlander
```

4. TESTA IN PRODUZIONE:
- Vai su https://highlandergame.it/forgot-username
- Apri Developer Tools > Console
- Inserisci email e clicca "Invia Username"
- Controlla i log nella console

ALTERNATIVA - DEPLOY SCRIPT AUTOMATICO:
```bash
cd /home/highlander
./deploy.sh
```

I log mostreranno esattamente dove fallisce la richiesta.
