COMANDI IMMEDIATI PER REPOSITORY VUOTO
=====================================

Esegui questi comandi nella shell di Replit:

# 1. Rimuovi lock Git
rm -f .git/index.lock

# 2. Forza push su GitHub
git push -f origin main

# 3. Se fallisce, reset e riprova
git reset --soft HEAD~1
git add .
git commit -m "Initial: App Highlander completa"
git push -f origin main

VERIFICA:
Vai su https://github.com/Fabiodi1995/highlander-serie-a
e controlla che i file siano presenti.

Se ancora vuoto:
1. Elimina repository su GitHub
2. Crea nuovo repository vuoto
3. Ripeti setup Git da capo
