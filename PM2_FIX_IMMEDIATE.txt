RISOLUZIONE DEFINITIVA PROBLEMA DATABASE
=======================================

Esegui questo script completo sul server:

```bash
ssh root@78.47.123.128
cd /home/highlander/app

# 1. Sync con repository
git fetch origin main
git reset --hard origin/main
npm install
npm run build

# 2. Verifica e crea schema database
sudo -u postgres psql -d highlander_db << 'EOSQL'
-- Verifica tabelle esistenti
\dt
-- Se non ci sono output, le tabelle non esistono
EOSQL

# 3. Forza creazione schema con Drizzle
npm run db:push

# 4. Restart PM2 completamente
pm2 delete highlander
pm2 start ecosystem.config.cjs

# 5. Verifica finale
pm2 status
pm2 logs highlander --lines 10

# 6. Test API
curl -X POST https://highlandergame.it/api/forgot-username \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com"}'
```

Questo script risolverà tutti i problemi database e riavvierà l'applicazione da zero.
