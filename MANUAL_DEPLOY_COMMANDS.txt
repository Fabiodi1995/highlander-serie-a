COMANDI DEPLOY MANUALE - GUIDA RAPIDA
=====================================

## DA REPLIT A GITHUB (dopo modifiche qui)

```bash
# 1. Verifica modifiche
git status

# 2. Aggiungi file modificati
git add .

# 3. Commit con messaggio
git commit -m "Fix: Aggiornato ecosystem.config.cjs e risolto login"

# 4. Push su GitHub
git push origin main
```

## DA GITHUB AL SERVER HETZNER

```bash
# Connetti al server
ssh root@78.47.123.128

# Vai nella directory app
cd /home/highlander/app

# Ferma l'applicazione
pm2 stop highlander

# Aggiorna dal repository
git pull origin main

# Installa eventuali nuove dipendenze
npm install

# Ricompila l'applicazione
npm run build

# Riavvia l'applicazione
pm2 start ecosystem.config.cjs

# Verifica stato
pm2 list
pm2 logs highlander --lines 10
```

## SCRIPT RAPIDO (da salvare sul server)

Crea `/home/highlander/deploy.sh`:
```bash
#!/bin/bash
cd /home/highlander/app
pm2 stop highlander
git pull origin main
npm install
npm run build
pm2 start ecosystem.config.cjs
echo "Deploy completato!"
pm2 list
```

Uso: `chmod +x deploy.sh && ./deploy.sh`
